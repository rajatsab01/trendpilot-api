# Trend Pilot - AI Trading Assistant

## Overview
Trend Pilot is an AI-powered financial advisory tool designed to provide intelligent buy/sell recommendations and bracket order analysis across various financial markets (Stock, Commodity, Forex, Cryptocurrency). It utilizes Perplexity AI with real-time web search for market data validation, symbol correction, and price discovery, eliminating the need for external market data APIs. The system supports 12 languages, multi-currency analysis with over 20 global currencies, and offers exchange/market preference selection for precise symbol resolution. Operating on a token-based usage model, it functions strictly as an ADVISORY-ONLY tool without trade execution capabilities. Its core ambition is to offer comprehensive, AI-driven financial guidance to enhance decision-making for traders and investors globally. The project aims to provide a social trading network, allowing users to publish analyses, follow others, and engage with community features like reactions and pinned traders.

## User Preferences
Preferred communication style: Simple, everyday language.

## System Architecture

### UI/UX Decisions
The frontend is built with React 18, TypeScript, and Vite, featuring a responsive, mobile-first dark mode UI. It uses a fintech-focused color palette, Spline Sans and Manrope fonts, Material Symbols Outlined icons, and `shadcn/ui` components (based on Radix UI) styled with Tailwind CSS. The design emphasizes a clean, simple analyzer form, incorporating features like a dedicated "Analyse More" button, a "Charity brings luck" donation feature, and a "Watch Ad" feature for earning tokens. The application includes a custom TrendPilot logo image displayed consistently across Welcome, Login, and Dashboard pages with the "TrendPilot" heading (in #38e07b green) and "AI-Powered Trading Analyzer" tagline for brand consistency. The bottom navigation has been streamlined to 4 tabs: Home, Saved, Community, and Policy (Analyzer tab removed). The symbol search autocomplete dropdown is positioned directly below the input field for better mobile visibility. A 90% zoom scale (`transform: scale(0.9)`) is applied to the Dashboard page on mobile viewports (<768px) for better content overview. The application features a global currency selector, embedded TradingView chart, "Saved" tab with dashboard for tracking trade outcomes, and compact card design for saved analyses. Community features include reaction buttons for published analyses and the ability to pin favorite traders. The version update modal uses "Install New Version" button with clear messaging that older versions may stop working, emphasizing service continuity for PWA updates.

### Technical Implementations
The backend is an Express.js application in TypeScript, following a RESTful API design with ES modules and a session-based architecture. It manages user authentication, market analysis via Perplexity AI, analysis history, and real market data fetching. JSON-based requests/responses with Zod for schema validation and robust error handling are employed. Symbol validation and autocomplete are handled server-side using Yahoo Finance and CoinGecko. The system includes backend API routes for community features such as reactions and pinning traders, with version guard protection and cache invalidation.

### Feature Specifications
Trend Pilot supports 12 languages and multi-currency analysis (20+ global currencies) across 44+ countries/regions. It operates on a token-based usage model, providing advisory-only recommendations. Perplexity AI (sonar-pro model) is the single source of truth for market data, handling symbol validation, market type auto-detection, exchange-aware symbol resolution, and analysis using real-time web search with market-specific research sources. The system generates structured analysis covering technical indicators, bracket order calculations (ensuring a minimum 1:3 risk-reward ratio), risk-reward ratios, multiple take-profit targets, support/resistance levels, probability meters (requiring 60%+), and trailing stop recommendations. It incorporates a comprehensive PWA installation strategy. Analysis results display both live market prices and analysis-based candle close prices with timestamps (converted to user's preferred currency), along with an embedded TradingView chart dynamically matching the analysis timeframe. Users can save analyses and track their trade status and performance. Community features allow users to publish analyses, react to them, and pin traders.

### System Design Choices
State management uses TanStack Query for server state and React Context API for global state. Wouter handles client-side routing with protected routes. Neon serverless PostgreSQL is the primary database, with Drizzle ORM for type-safe operations. The data model includes `Users` (with `currency` and `exchange` preferences), `Analyses` (storing `currency` and `exchange` per analysis), `Brokers`, `reactions`, and `pinnedTraders`, using UUIDs for primary keys. Authentication uses Phone.Email for phone number verification, and authorization is `userId`-based. Security measures include SSRF protection, HTTPS enforcement, Zod input validation, and Drizzle ORM for SQL injection protection. Perplexity AI automatically detects market type, uses exchange preference for precise symbol resolution, and ensures mandatory candle close prices with duration-specific timeframes for accurate analysis. All prices are converted to the user's preferred currency, with scalping analyses incorporating live prices for entry/TP/SL. A comprehensive 4-tier symbol validation system ensures data quality and prevents wasted AI tokens, including a Symbol Registry, Instrument Database, Symbol Tester, and Pre-flight Validation. The application includes a mandatory version checking system and a social trading network with an admin system for moderation and monitoring.

**Forex Pair Handling:** Forex pairs receive special treatment to preserve their nature as exchange rates. The system extracts the quote currency (2nd currency in the pair) using `getQuoteCurrency()` and displays all prices in that currency without conversion. For example, USD/GBP shows prices in GBP (£), while GBP/USD shows prices in USD ($). The `getExchangeCurrency()` function returns the quote currency for forex pairs, ensuring `sourceCurrency` correctly identifies the display currency. The frontend detects forex pairs via `analysis.market === 'forex'` and uses `analysis.sourceCurrency` for symbol display instead of the user's preferred currency. This approach maintains the integrity of forex pairs as exchange rates rather than convertible prices.

**Commodity Futures Handling:** Commodity futures (symbols with =F suffix like GC=F, SI=F, CL=F) are ALWAYS priced in USD from Yahoo Finance. The `getExchangeCurrency()` function prioritizes commodity futures detection (checking for =F suffix) BEFORE checking exchange suffixes to prevent false matches (e.g., SI=F should not match Singapore Exchange .SI suffix). This critical ordering ensures all commodity futures (gold, silver, oil, natural gas, etc.) consistently return 'USD' as the source currency. All commodity prices are sourced in USD and then converted to the user's preferred currency. TradingView chart mappings transform futures symbols to their CFD equivalents (SI=F→XAGUSD, GC=F→XAUUSD, CL=F→USOIL) for proper chart rendering.

**Multi-Endpoint Commodity Validation:** The system uses a comprehensive smart fallback chain with exchange shortforms (CMX for COMEX, NYM for NYMEX, CBT for CBOT) to ensure accurate commodity data retrieval. For each commodity futures symbol, the `testCommodityFuturesMultiEndpoint()` function sequentially tests: (1) Exchange-prefixed symbol via Chart API (e.g., CMX:SI=F), (2) Exchange-prefixed symbol via Quote API, (3) Non-prefixed symbol via Chart API (e.g., SI=F), (4) Non-prefixed symbol via Quote API. This multi-endpoint approach maximizes the chances of retrieving correct commodity prices, with detailed logging at each step to diagnose issues. The `fetchYahooSuggestions()` function displays commodity futures with exchange prefixes in autocomplete (e.g., "CMX:SI=F - Silver Futures (CMX)") to guide users toward the correct format.

**Advisory Price Validation:** The system includes COMMODITY_FUTURES_METADATA defining expected USD price ranges (min/max), full descriptive names (e.g., "Silver Futures"), exchanges, and units for 15 liquid commodity contracts. Price validation is **advisory-only**: if a fetched price falls outside the expected range, a warning message is logged and can be surfaced to users, but the analysis proceeds rather than failing. This approach accommodates high volatility periods when commodity prices can double or halve rapidly, while still alerting users to potentially incorrect data (e.g., SI=F returning $48 instead of expected $25-35 range).
